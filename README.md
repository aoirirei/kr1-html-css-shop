# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара;
- `about.html` — страница «О нас»;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.

## Самостоятельные доработки

В рамках подготовки к сдаче КР №1 в проект добавлены следующие элементы:

- **Страница «О нас»** (`about.html`) — информация о компании, миссия, ценности, цифры.
- **Чат-виджет** — кнопка в правом нижнем углу с иконкой, окно чата с примерами сообщений. Открывается и закрывается через JavaScript.
- **Расширенный каталог** — 5 карточек товаров с реальными изображениями (фото корма, когтеточки, лотка, мисок).
- **Бейджи на карточках** — «Хит», «Скидка», «Новинка». Сделаны через `position: absolute`.
- **Хлебные крошки** — на всех внутренних страницах.
- **Единая навигация** — на всех страницах, с модификатором активной ссылки.
- **Таблица характеристик** — на странице товара.
- **Передача товара через URL** — `product.html?product=N` открывает нужный товар.

## Позиционирование

В проекте используются все основные виды позиционирования:

- `position: relative` — у карточки товара (`.product-card`), чтобы бейдж позиционировался внутри неё;
- `position: absolute` — у бейджа «Хит», «Скидка», «Новинка» (`.product-card__badge`);
- `position: fixed` — у кнопки чата (`.chat-button`) и окна чата (`.chat-window`);
- `z-index` — у чата (`100`), у окна чата (`99`), у бейджа (`1`).

## Как проверить проект

1. Открыть `index.html` в браузере.
2. Проверить переходы по всем страницам через меню.
3. На главной — кликнуть «Заказать» на любой карточке → откроется модалка.
4. Открыть `catalog.html` — 5 карточек с фото, фильтры слева.
5. Открыть `product.html` — карточка товара и таблица характеристик.
6. Открыть `about.html` — страница о компании.
7. Открыть `contacts.html` — контакты и ссылка на «О нас».
8. В правом нижнем углу — кнопка чата: клик открывает окно, крестик закрывает.
